方法40：反馈法 ★★★☆☆

利用反馈调节系统

← 返回主页面
📖 方法详解

反馈法是将系统的输出信号返回到输入端，与输入信号进行比较，利用偏差信号对系统进行控制的方法。反馈是控制论的核心概念，广泛应用于电子电路、自动控制系统、生物系统等领域。

核心原理

  • 负反馈：反馈信号削弱输入信号，使系统稳定
  • 正反馈：反馈信号增强输入信号，使系统发散
  • 反馈控制：通过比较偏差进行调节
  • 闭环系统：包含反馈回路的控制系统
反馈系统的基本关系：
开环增益：$A$
反馈系数：$\beta$
闭环增益：$A_f = \frac{A}{1 + A\beta}$（负反馈）
深度负反馈：当 $A\beta \gg 1$ 时，$A_f \approx \frac{1}{\beta}$
🎯 适用场景详解
  • 放大电路：稳定增益、改善性能
  • 自动控制系统：温度、速度、位置控制
  • 振荡电路：利用正反馈产生振荡
  • 稳压电源：稳定输出电压
  • 生物调节：体温调节、血糖调节

典型问题类型

  • 运算放大器：比例、积分、微分运算
  • 稳压电路：串联型、并联型稳压
  • 振荡器：RC振荡、LC振荡
  • 控制系统：PID控制、伺服系统
💡 核心要点与技巧
1 判断反馈类型
  • 正反馈：输出与输入同相，增强作用
  • 负反馈：输出与输入反相，削弱作用
  • 瞬时极性法判断反馈极性
2 分析反馈效果
  • 负反馈：稳定增益、展宽频带、减小失真
  • 正反馈：产生振荡、加速翻转
  • 深度负反馈：增益仅取决于反馈网络
3 计算闭环参数
  • 确定开环增益和反馈系数
  • 应用闭环增益公式
  • 分析输入输出阻抗变化
⚠️ 常见错误
  • 反馈极性判断错误
  • 混淆开环增益与闭环增益
  • 忽略反馈网络的负载效应
  • 正反馈条件下求稳定增益
📝 典型例题
例题1：负反馈放大器

题目：某放大器开环增益 $A = 1000$，引入负反馈后闭环增益 $A_f = 100$。求反馈系数 $\beta$ 和反馈深度。

解法：

反馈深度：
$F = 1 + A\beta = \frac{A}{A_f} = \frac{1000}{100} = 10$

反馈系数：
$A\beta = F - 1 = 9$
$\beta = \frac{9}{A} = \frac{9}{1000} = 0.009$

验证：
$A_f = \frac{A}{1+A\beta} = \frac{1000}{1+9} = \frac{1000}{10} = 100$ ✓

答案：反馈系数 $\beta = 0.009$，反馈深度 $F = 10$
例题2：运算放大器电路

题目：理想运放组成的反相比例运算电路，输入电阻 $R_1 = 10$ kΩ，反馈电阻 $R_f = 100$ kΩ。求闭环电压增益。

解法：

电路分析：
反相输入端虚地：$V_- = 0$
输入电流：$I_i = \frac{V_i - V_-}{R_1} = \frac{V_i}{R_1}$
反馈电流：$I_f = \frac{V_- - V_o}{R_f} = -\frac{V_o}{R_f}$

利用虚断：
$I_i = I_f$
$\frac{V_i}{R_1} = -\frac{V_o}{R_f}$

闭环增益：
$A_f = \frac{V_o}{V_i} = -\frac{R_f}{R_1} = -\frac{100}{10} = -10$

说明：
负号表示输出与输入反相
增益仅由电阻比决定，与运放参数无关（深度负反馈）

答案：闭环电压增益 $A_f = -10$
