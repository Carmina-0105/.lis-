方法41：叠加原理法 ★★★★★

多个源作用的叠加

← 返回主页面
📖 方法详解

叠加原理是线性系统的基本性质。对于由多个独立源作用的线性系统，其总响应等于各独立源单独作用时产生的响应之和。这一原理在电路分析、力学、振动分析等领域有广泛应用。

核心原理

  • 线性性质：系统满足齐次性和可加性
  • 独立性：各源的作用互不影响
  • 可叠加性：总响应等于分响应之和
  • 适用范围：仅适用于线性系统
叠加原理的数学表达：
若 $x_1 \rightarrow y_1$，$x_2 \rightarrow y_2$
则 $a x_1 + b x_2 \rightarrow a y_1 + b y_2$

电路中的叠加：
电压源置零 → 短路
电流源置零 → 开路
🎯 适用场景详解
  • 多源电路：多个电源共同作用的电路
  • 线性网络：由线性元件组成的电路
  • 振动分析：多个激励的叠加
  • 场强计算：多个电荷产生的场
  • 波动光学：多束光的干涉

典型问题类型

  • 直流电路：多个电压源、电流源
  • 交流电路：不同频率的电源
  • 电场计算：点电荷系的场强
  • 振动合成：多个简谐振动的叠加
💡 核心要点与技巧
1 判断线性
  • 确认系统是否线性
  • 检查是否含有非线性元件
  • 非线性系统不能使用叠加原理
2 逐个处理
  • 保留一个源，其他源置零
  • 电压源短路，电流源开路
  • 计算该源单独作用的响应
3 叠加结果
  • 代数相加各分响应
  • 注意方向（正负号）
  • 检查结果的合理性
⚠️ 常见错误
  • 对非线性系统应用叠加原理
  • 源置零方式错误
  • 忽略方向导致符号错误
  • 功率计算错误（功率不能叠加）
📝 典型例题
例题1：多源电路

题目：电路中有两个电压源 $E_1 = 10$ V 和 $E_2 = 5$ V，电阻 $R_1 = 2$ Ω、$R_2 = 3$ Ω、$R_3 = 5$ Ω。求流过 $R_3$ 的电流。

解法：

第一步：$E_1$ 单独作用（$E_2$ 短路）
等效电阻 $R' = R_1 + \frac{R_2 R_3}{R_2 + R_3} = 2 + \frac{3 \times 5}{3 + 5} = 2 + 1.875 = 3.875$ Ω
总电流 $I' = \frac{E_1}{R'} = \frac{10}{3.875} = 2.58$ A
分流得 $I_3' = I' \times \frac{R_2}{R_2 + R_3} = 2.58 \times \frac{3}{8} = 0.97$ A（向下）

第二步：$E_2$ 单独作用（$E_1$ 短路）
等效电阻 $R'' = R_2 + \frac{R_1 R_3}{R_1 + R_3} = 3 + \frac{2 \times 5}{2 + 5} = 3 + 1.43 = 4.43$ Ω
总电流 $I'' = \frac{E_2}{R''} = \frac{5}{4.43} = 1.13$ A
分流得 $I_3'' = I'' \times \frac{R_1}{R_1 + R_3} = 1.13 \times \frac{2}{7} = 0.32$ A（向上）

第三步：叠加
$I_3 = I_3' - I_3'' = 0.97 - 0.32 = 0.65$ A（向下）

答案：流过 $R_3$ 的电流为 $0.65$ A，方向向下
例题2：点电荷电场

题目：两个点电荷 $q_1 = +2$ μC 和 $q_2 = -3$ μC 相距 $d = 0.1$ m。求连线中点处的电场强度。

解法：

分析：
中点距离每个电荷 $r = 0.05$ m

$q_1$ 产生的场强：
$E_1 = k\frac{|q_1|}{r^2} = 9 \times 10^9 \times \frac{2 \times 10^{-6}}{(0.05)^2} = 7.2 \times 10^6$ N/C
方向：远离 $q_1$（设向右为正）

$q_2$ 产生的场强：
$E_2 = k\frac{|q_2|}{r^2} = 9 \times 10^9 \times \frac{3 \times 10^{-6}}{(0.05)^2} = 10.8 \times 10^6$ N/C
方向：指向 $q_2$（向右，因 $q_2$ 为负）

叠加：
两场强同向，均向右
$E = E_1 + E_2 = 7.2 \times 10^6 + 10.8 \times 10^6 = 18 \times 10^6$ N/C
方向：由 $q_1$ 指向 $q_2$

答案：$E = 1.8 \times 10^7$ N/C，方向由正电荷指向负电荷
